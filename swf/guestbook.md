欢迎交流游戏、反馈汉化问题、提出补档建议或申请友链。

本站通过 GitHub Issues 收集留言。点击下方链接后，需要登录 GitHub 才能提交；留言会公开显示，请勿填写私密信息。

[前往 GitHub 留言 ↗](https://github.com/WestCreeper/westcreeper.github.io/issues)

## 游戏问题反馈

请尽量提供以下信息，方便定位：

- 游戏名称与页面地址
- 浏览器、设备，以及问题出现的步骤
- 错误提示或截图（如有）

## 申请友链

请附上你的网站名称、地址、简介和头像链接。期待认识更多认真经营自己小站的人。
